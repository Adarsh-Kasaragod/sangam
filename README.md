# Event App

A web app for managing college events. Students can browse and register for events. Admins can create, edit and delete events.

## Tech Used
- React (frontend)
- PHP + MySQL (backend)
- Vite for dev server

## How to Run

1. Start XAMPP (Apache + MySQL)
2. Copy project to `C:\xampp\htdocs\event-app`
3. Create database `event_app` and import `database/schema.sql`
4. Run frontend:
```
cd frontend
npm install
npm run dev
```
5. Open http://localhost:5173
